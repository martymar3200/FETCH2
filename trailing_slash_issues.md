# Trailing Slash Issues in Backend Routers
This report lists all API router endpoints in the backend that use **dynamic path parameters** (e.g., `{id}`) but **do not end with a trailing slash (`/`)**.
Calling these endpoints from the frontend with a trailing slash (e.g., `/users/{id}/` instead of `/users/{id}`) causes a 307 Redirect on FastAPI, which can result in mixed-content block errors (HTTP vs HTTPS) in secure environments.
